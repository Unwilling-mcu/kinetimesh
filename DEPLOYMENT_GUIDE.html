Quick Start

Step 1: Fix directory structure

# In PowerShell inside KinetiMesh folder:
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
.\setup.ps1

Step 2: Start full stack

cd infra
docker compose up -d
docker compose ps   # all should show "running"

Step 3: Open demo files

Start-Process "index.html"
Start-Process "KinetiMesh_v3_FullStack.html"

ML Training Pipeline

1. FedProx FL (already tested — kinetimesh_fl_best.pt exists)

cd ml\federated
# Quick test (30 seconds)
python train_fedprox.py --nodes 6 --rounds 8 --mu 0.01
# Full training
python train_fedprox.py --nodes 18 --rounds 100 --mu 0.01
✓
kinetimesh_fl_best.pt in your project root is a real trained checkpoint. Global MAE dropped 0.94 → 0.12 across 8 rounds during our live run.

2. PPO Reinforcement Learning

cd ml\rl
pip install stable-baselines3 gymnasium
python train_ppo.py --timesteps 10000   # quick test
python train_ppo.py --timesteps 1000000 # full (30min GPU, 2h CPU)

3. GraphSAGE Digital Twin

cd ml\gnn
python digital_twin.py
# Expected: 18 nodes, GNN error ~4.4%

Edge Node Deployment

Simulate locally

python edge\edge_node.py

Deploy to Raspberry Pi CM4 (production)

pip install mpremote
# Edit NODE_ID and MQTT_BROKER in edge_node.py first
mpremote connect COM3 cp edge\edge_node.py :main.py
⚠
Replace read_piezo_voltage() stub with actual ADC reads from GPIO pins connected to the PZT tile. Everything else works unchanged.
